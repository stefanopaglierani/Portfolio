Robust Logging System

When a system fails on the edge, logs are the only diagnostic tool. Here is a snippet of the logging architecture designed to run silently without filling up IPC storage:


import logging
import os
from logging.handlers import RotatingFileHandler

def setup_logger():
    log_dir = "C:\\EdgeSentinel\\Logs"
    if not os.path.exists(log_dir):
        os.makedirs(log_dir)
        
    log_file = os.path.join(log_dir, 'sentinel_monitor.log')
    handler = RotatingFileHandler(log_file, maxBytes=5*1024*1024, backupCount=3)
    formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s')
    handler.setFormatter(formatter)
    
    logger = logging.getLogger('EdgeSentinel')
    logger.setLevel(logging.INFO)
    logger.addHandler(handler)
    
    return logger

Deployment: The Standalone Executable

To avoid "dependency hell" on production machines, I packaged the entire Python application into a single, standalone executable (`.exe`) using PyInstaller. This ensures Edge Sentinel can be deployed via a simple file copy with zero setup time on the target IPC.

pyinstaller --noconsole --onefile edge_sentinel.py

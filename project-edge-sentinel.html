Edge Sentinel

A lightweight Python service for industrial PCs that tracks the wear of the CMOS backup battery and raises a flag before it fails, so a routine power cycle on the factory floor doesn't turn into a hard reset and lost settings.

The problem

On a factory floor, industrial PCs run machines for years. The small battery that keeps their clock and settings alive wears out quietly.

Nobody notices until the day the machine is switched off for maintenance and comes back with a reset clock and lost configuration. There is usually no early warning for the technician. I had seen that happen, and wanted a tool that warns weeks before, without touching the machine's own control software.

How it works

config.jsonInstallation date and expected lifespan in years
Windows serviceWakes every 5 seconds, computes wear as a percentage
ui_flag.jsonStatus, wear and whether to show an alarm
Any UIWatches the file and shows a popup only when needed
Green, OKBelow 80% of the expected lifespan
Yellow, attention80% to 95%: plan the replacement
Red, replace now95% and above: the alarm flag turns on

Every start, stop and check is written to a timestamped log, logs/battery_health.log. A missing or corrupted configuration file never crashes the service: the error is logged and the next check tries again.

Decisions that matter

A real Windows service, not a script in a console

A plain Python script needs an open console and a logged-in user, and it can be closed by accident. Wrapping the logic with win32serviceutil makes it a native service: it starts with the machine, runs without anyone logged in, and stops cleanly when Windows asks instead of being killed.

class EdgeSentinelService(win32serviceutil.ServiceFramework):
    _svc_name_ = "EdgeSentinel"
    _svc_display_name_ = "Edge Sentinel Battery Monitor"

    def SvcStop(self):
        # Windows asks the service to stop
        self.ReportServiceStatus(win32service.SERVICE_STOP_PENDING)
        win32event.SetEvent(self.stop_event)

    def main(self):
        while True:
            # Instead of time.sleep(): wait 5 s, but wake up at once on a stop signal
            rc = win32event.WaitForSingleObject(self.stop_event, 5000)
            if rc == win32event.WAIT_OBJECT_0:
                break
            try:
                config = carica_configurazione()
                usura = calcola_usura(config["install_date"], float(config["lifespan_years"]))
                salva_stato_ui(usura, determina_stato(usura))
            except Exception as e:
                logging.error(f"Error reading or calculating: {e}")

Waiting on the stop event instead of sleeping is the detail that makes the service shut down in milliseconds instead of hanging for up to five seconds.

Never interrupt the machine's software

A service running as SYSTEM can't open windows on the operator's screen, and it shouldn't. So Edge Sentinel only writes a small JSON file. A separate interface can watch that file and show a popup only when mostra_popup_allarme is true. The monitoring logic and the machine's control software never share a process.

Paths that survive packaging

The service ships as a single executable built with PyInstaller, so the target machine doesn't need Python. A frozen executable resolves relative paths from a different working folder, so the service anchors everything to its own location and creates its folders on the first run:

if getattr(sys, 'frozen', False):
    BASE_DIR = os.path.dirname(sys.executable)
else:
    BASE_DIR = os.path.dirname(os.path.abspath(__file__))
os.chdir(BASE_DIR)

os.makedirs('logs', exist_ok=True)
os.makedirs('output', exist_ok=True)

Install

A technician copies the executable and config.json into one folder and runs two commands from an administrator prompt:

edge_sentinel_svc.exe install
edge_sentinel_svc.exe start

It's a small project and an honest one: not running in a factory today, but a complete example of the unattended, fail-safe software I want to keep building for manufacturing.

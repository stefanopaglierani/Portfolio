Project overview

Da Vinci Glamping Resort is a self-funded, personal entrepreneurial project: a concept for an off-grid hospitality site combining clean energy infrastructure with smart-home automation. It runs alongside my main employment, not in place of it.

The project is still at the concept and validation stage. No physical site or software infrastructure has been built yet; the work so far has been design and outreach.

What exists today

  • Concept design. Planning how clean energy systems and smart-home automation would work together in an off-grid setting.
  • Public validation. Instagram and TikTok pages set up to gauge interest and build an audience ahead of a planned crowdfunding campaign.

What I learned

The social outreach hasn't generated meaningful traction yet, and the crowdfunding effort hasn't launched. I keep this project listed because it reflects genuine entrepreneurial initiative and the same systems thinking I bring to software: start from a concept, break it into concrete pieces (energy, automation, audience), and be honest about which pieces are actually built.
